# Credits

## Code
Original work for Realistic Natural Disasters. No code from other mods was used.
Project skeleton: the official NeoForge MDK (`NeoForgeMDKs/MDK-26.1.2-ModDevGradle`, MIT template license).

## Sounds (all original, CC0)
Synthesized from filtered noise by `tools/gen_sounds.py`; regenerate any time. Dedicated to the public domain (CC0 1.0).

| File | Description |
|---|---|
| `tornado_distant.ogg` | far "freight train" rumble loop (resonant 50–300 Hz, rhythmic chug) |
| `tornado_roar.ogg` | mid-range rushing roar loop |
| `tornado_core.ogg` | overwhelming close-range roar loop with debris crackle |
| `wind_howl.ogg` | wind whistling around obstacles (pitch-sweeping resonances) |
| `rumble1-3.ogg` | rolling thunder (crack + rumble) |
| `wind_gust1-3.ogg` | wind gusts |
| `debris_thud1-3.ogg` | heavy debris impacts |
| `wood_snap1-3.ogg` | tree trunks snapping (crack, splinters, creak) |
| `debris_rattle1-3.ogg` | small debris pelting the surroundings |

## Textures (all original, CC0)
Generated by `tools/gen_textures.py`: soft 64x64 fractal-noise cloud, cloud-base, funnel-streak, dust and rain-curtain
textures, 8x8 debris specks, mod logo, the replacement `minecraft:textures/environment/rain.png` (realistic rain), and the
seamless funnel mesh textures `textures/entity/funnel_core.png`, `funnel_veil.png` and `debris_sheath.png`.
