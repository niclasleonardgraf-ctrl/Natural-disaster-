# Credits

## Code
Original work for Realistic Natural Disasters. No code from other mods was used.
Project skeleton: the official NeoForge MDK (`NeoForgeMDKs/MDK-26.1.2-ModDevGradle`, MIT template license).

## Sounds (all original, CC0)
Synthesized from filtered noise by `tools/gen_sounds.py`; regenerate any time. Dedicated to the public domain (CC0 1.0).

| File | Description |
|---|---|
| `tornado_roar.ogg` | close roar loop (low rush + gritty mid band, slow surges) |
| `tornado_distant.ogg` | far freight-train rumble loop |
| `rumble1-3.ogg` | distant thunder-like rumbles (warning signs) |
| `wind_gust1-3.ogg` | wind gusts |
| `tsunami_roar.ogg` | close loop of the bore (deep churning roar, white-water hiss, grinding and snapping debris) |
| `tsunami_surf.ogg` | distant heavy-surf loop (slow swells over a low ocean rumble) |
| `tsunami_crash1-3.ogg` | one-shot impacts (thump, broadband crash, splintering wood, seething tail) |

## Textures (all original, CC0)
Generated by `tools/gen_textures.py`: soft 64x64 fractal-noise cloud, cloud-base, funnel-streak, dust and rain-curtain
textures, 8x8 debris specks, mod logo, the replacement `minecraft:textures/environment/rain.png` (realistic rain), and
soft 64x64 tsunami whitewater / spray plus 32x32 droplet and floating-debris sprites.

## Test structure
`data/realisticdisasters/structure/tornado_arena.nbt` and `tsunami_arena.nbt`, generated by `tools/gen_structures.py`.
