# Builds

Downloadable test builds of Realistic Natural Disasters. The source code lives on `main`.

| File | Contents | Requires |
|---|---|---|
| `realisticdisasters-1.0.0-tornado-preview.jar` | Tornado only (preview) | Minecraft 26.1.2, NeoForge 26.1.2.126+, Java 25 |

Install: put the jar in `.minecraft/mods`, start the NeoForge profile, then use `/disaster start tornado 3` in a test world.
Note: the tornado damages blocks, and the mod replaces the vanilla rain texture.
