# Builds

Downloadable test builds of Realistic Natural Disasters. Source code: `main` (tornado) and `integration/all-disasters` (everything).

| File | Contents | Requires |
|---|---|---|
| `realisticdisasters-1.0.0-all-disasters.jar` | **All seven disasters**: tornado, earthquake, wildfire, volcano, meteor shower, tsunami, blizzard + sandstorm | Minecraft 26.1.2, NeoForge 26.1.2.126+, Java 25 |
| `realisticdisasters-1.0.0-tornado-preview.jar` | Older tornado-only preview (superseded) | same |

Install: put the jar in `.minecraft/mods` (official launcher with the NeoForge installer, or a Modrinth/Prism NeoForge instance) and start a test world with cheats.
Try: `/disaster start tornado 3`, `earthquake`, `wildfire`, `volcano`, `meteor_shower`, `tsunami`, `blizzard`, `sandstorm`; `/disaster stop` to end one.
Note: disasters really damage the world, and the mod replaces the vanilla rain texture.
